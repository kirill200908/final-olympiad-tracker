# Финал — олимпиадный трекер

Статический сайт на русском для подготовки к IV этапу республиканской олимпиады Беларуси по информатике. Работает на GitHub Pages без сервера, API-ключей и регистрации.

## Возможности

- Готическая чёрная тема: графитовые панели, серебристые детали, светлая типографика и арочный знак.
- Журнал Codeforces и CSES: самостоятельные решения и решения с разбором.
- Каталог 11 526 задач CF и 400 CSES, снимок 15 ноября 2026 года. Официальный рейтинг CF; 110 авторских оценок CSES, остальные можно ввести вручную.
- Четыре взаимно исключающих исхода: I, II, III диплом и без диплома, сумма 100%.
- Сравнение с задачами обоих дней финалов 2024, 2025 и 2026, обоснование диапазонов CF, историческая статистика, источники.
- Локальное сохранение, редактирование и удаление, поиск и фильтры, экспорт и объединяющий импорт JSON.
- Демо работает отдельно в памяти и не меняет собственный журнал.

## Прогноз на финал 2027

Главный экран использует все три последних финала одновременно. Сначала отдельно рассчитываются вероятности дипломов по задачам и границам каждого года. Затем смешиваются неокруглённые вероятности: 2024 — 20%, 2025 — 30%, 2026 — 50%. Итог отображается с точностью до 0,1%, сумма — 100%. Веса — авторское допущение; будущие задания и пороги могут отличаться. Переключатель года в источниках меняет только исторический разбор.

Цепочка расчёта: самостоятельные решения CF/CSES → модельный уровень CF → вероятность полного и частичного решения каждой задачи финала → распределение суммы баллов → четыре исхода по историческим границам дипломов. Ник или профиль Codeforces для этого не требуется.

До поправок вероятность преодолеть сложность R при уровне S равна `1 / (1 + exp((R − S) / 240))`. При совпадении уровней это 50%. Для полного решения берётся середина авторского диапазона CF; для частичных баллов — отдельные модельные ступени. По умолчанию 25% ожидаемого балла задаёт историческая статистика, 75% — CF-модель. Статистическая поправка сдвигает шансы всех ступеней на одну величину в шкале логарифма шансов, сохраняя их порядок. Её можно отключить в настройках.

Ступени одной задачи вложены: полное решение включает частичные баллы. Распределения восьми задач складываются с учётом всех комбинаций баллов, затем учитывается дополнительный разброс формы. Этот расчёт точен относительно принятых дискретных распределений; он не доказывает точность самих предположений. Независимость результатов задач до поправки на форму, масштаб 240, стартовый уровень 1100 и опорный уровень статистики 1900 — допущения модели.

## Что означает прогноз

19 ноября 2026 года проведён повторный аудит всех 24 задач по алгоритмам. Например, 2026 1.A снижена с 1600–1900 до 1300–1500 CF: достаточно весов позиций, сортировки и префиксов выгодных обменов. Для 18 задач установлен полный алгоритм обычной части. Пять полных оценок остаются явно предварительными: 2024 1.D; 2025 1.D и 2.C; 2026 1.C и 1.D. Численные CF-диапазоны во всех случаях авторские.

Открытые тесты не получают обычный полный CF-рейтинг. 2024 2.D моделируется по историческому распределению баллов. Для 2026 2.D отдельно складываются распределения обычных 70 баллов (CF 2500–2800) и открытых 30 баллов. В открытой части веса исторических исходов умножаются на `exp((уровень−1900)/350 × балл/максимум)`; к нулю и максимуму добавлено по одному условному наблюдению. Это дополнительное предположение, не измеренная связь CF с качеством эвристик. Вес статистики в настройках относится к обычным задачам. Старые поля range/bands в полностью открытой задаче сохранены для совместимости закэшированных клиентов; новая модель и интерфейс их как CF-оценку не используют.

Прогноз экспериментальный: нет обучающей выборки, связывающей журналы CF/CSES с результатами реальных финалистов. Диапазоны CF задач финала, ступени частичных баллов и связь уровня с баллами — авторские допущения, открыто описанные в разделе «Модель и источники».

Самостоятельные решения подтверждают уровень; решения с разбором попадают в план повторения, но не повышают оценку самостоятельной силы. Проценты появляются сразу после первого самостоятельного решения с известной сложностью за последний год. При 1–4 решениях показывается высокая неопределённость. Сложность CSES не является официальным рейтингом CF.

Исторические минимумы дипломантов (I / II / III):

| Год | I | II | III | Точность |
| --- | --- | --- | --- | --- |
| 2024 | ≈426 | ≈308 | ≈207 | Округлённые баллы CLIST |
| 2025 | 476 | 405 | 293 | Первичная итоговая таблица |
| 2026 | ≈477 | ≈393 | ≈292 | Округлённые баллы CLIST |

В 2024 и 2026 были задания с открытыми тестами и дробными оценками. Это минимальные баллы награждённых в прошлом, не пороги будущей олимпиады. Для 2026 две части D второго дня (70+30) объединены в одну задачу.

## Локальный запуск

Нужен Node.js 20 или новее. В этой папке:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Сборка и установка пакетов не нужны. Проверки: `npm test`.

## Публикация в GitHub Pages

Загрузите содержимое папки в корень репозитория. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/(root)`, затем Save. Все пути относительные, поэтому сайт работает в репозитории с любым именем.

## Данные и приватность

Журнал хранится только в localStorage текущего браузера на текущем адресе сайта. GitHub не получает журнал через этот сайт. При смене адреса, устройства или очистке данных браузера восстановите журнал из экспортированного JSON. Импорт объединяет записи по платформе и номеру; записи из копии заменяют совпадения. Исходники содержат только обезличенную историческую статистику.

Повреждённый локальный журнал восстанавливается по корректным записям. До следующего сохранения исходная строка сохраняется отдельно; скачать её можно в блоке восстановления на сайте. Дубли с ведущими нулями считаются одной задачей, а обе исходные записи остаются в этой копии.

Вкладки объединяют независимые изменения; удалённая в другой вкладке задача не возвращается из устаревшей формы. Web Locks сериализует одновременные сохранения. Если браузер не поддерживает Web Locks, последовательные изменения объединяются, но для одновременной работы используйте одну вкладку.

Google Fonts используется для оформления; при недоступности работает системный шрифт. Кнопка обновления CF обращается к публичному API, при сетевых ограничениях остаётся встроенный каталог.
